# Docker image policy

No Docker image has been published or qualified for Rails 8 AI Image Processing
API. The repository's Dockerfile is an imported baseline and its image name is
`dangkhoa2016/rails-8-ai-image-processing-api` when a later release process
authorizes publication.

Before publishing an image, the project must verify the Rails authentication
baseline, native libvips runtime when added, security checks, and the relevant
CPU/RAM qualification. Do not treat upstream container tags, registries, or
deployment results as artifacts of this project.
