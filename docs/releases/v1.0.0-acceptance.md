# v1.0.0 Final Acceptance Record

This document is the public acceptance record for the first stable source
release of Rails 8 AI Image Processing API.

`v1.0.0` represents the project's first public community source release. It is
identified by an annotated tag, a GitHub Release, and commit/tree authority
that are recorded after the final CI gate passes. Release metadata must
summarize the complete image-processing, AI-boundary, qualification, and
validation scope accepted for the release.

## Release identity

- Version: `v1.0.0`
- Channel: stable
- Public prerelease: none
- Initial community-publication closeout date: 2026-09-22
- Tag form: annotated
- Authoritative source: the peeled target of `v1.0.0`
- Publication rule: the tag target equals the exact `main` SHA that completes
  the mandatory public-main CI gates successfully immediately before final
  publication.
- Publication artifacts: the annotated tag, GitHub Release notes, and the
  public evidence asset must all describe that same final source and
  CI-qualified publication event.

This file intentionally does not hard-code the SHA of the commit that contains
it. Embedding that SHA would be self-referential and would change the commit
being identified. The annotated tag message, GitHub Release notes, the release
closeout record, and the public evidence asset record the exact final SHA,
tree, CI run, tag object, and asset hashes after the final CI gate passes.

## Stable release scope

### Image processing

The stable release includes the authenticated Rails 8 multipart image-processing
contract:

- `GET /images/capabilities`
- `POST /images/process` — deterministic Vips pipeline (JPEG, PNG, WebP)
- `POST /images/remove-background` — AI background removal (BiRefNet)

with explicit input/output/resource limits, strict operation validation,
metadata stripping, a stateless tempfile lifecycle, image-specific rate
limiting, and fail-closed behavior on AI when `IMAGE_AI_ENABLED` is not `true`.

### AI application boundary (from the qualified source)

- `POST /images/remove-background` is authenticated and exposed.
- Default foreground-mask provider: BiRefNet (ONNX Runtime CPU inside Ruby).
- Optional `background=#RRGGBB` performs deterministic solid-background
  composition with libvips; an omitted `background` returns transparent output.
- Optional parameters: `feather` (0–20), `format` (`png`/`webp`), `quality` (1–100).
- BiRefNet is not part of `POST /images/process`.
- Model weights are not embedded in Git; they are fetched out-of-band and
  checksum-verified against the pinned manifest before runtime loading. The
  application does not download weights automatically.

### Qualification scope

- BiRefNet quality validation on a fixed 32-image evaluation: 32/32 passed.
- Formal provider-capacity CPU runtime qualification passed in a
  provider-managed Modal Function container (CPU 2.0/2.0 cores, memory
  8192/8192 MiB, GPU none, no swap, one model load, session reuse PASS).
- `8192 MiB` is the first tested passing tier. No exact peak-RAM claim is made
  because the provider did not expose cgroup `memory.peak` telemetry.
- These are capacity/quality qualifications, not production-traffic or SLA
  claims.

## Excluded scope

The v1.0.0 source release does not include or claim:

- a hosted production deployment or live public endpoint;
- GHCR image publication;
- production-traffic or SLA qualification;
- GPU acceleration qualification;
- a Python inference service;
- an exact peak-RAM memory figure;
- that 8192 MiB is the theoretical minimum memory requirement.

New functionality or code corrections after this release use normal forward
history and an appropriate new version when warranted.
