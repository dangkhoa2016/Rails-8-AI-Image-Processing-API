# `v1.0.0` acceptance record

## Marker

`v1.0.0` is the sole mutable local release marker. Resolve its current exact
target with `git rev-parse v1.0.0^{commit}`. The annotated tag records the
target SHA and refresh timestamp.

## Included deterministic API scope

- Authenticated multipart image processing for JPEG, PNG, and WebP.
- Explicit resize, crop, rotate, flip, grayscale, color/filter, resource-limit,
  metadata-strip, tempfile-lifecycle, and image-rate-limit behavior.
- A test-only, CPU-only ONNX Runtime feasibility spike with a checksum-verified
  sigmoid fixture. It exposes no AI route, job, or image-processing operation.
- U²-NetP provenance tooling: a pinned upstream checkpoint, reproducible
  CPU-only ONNX conversion recipe, checksum-validated local fetch/install, and
  no checked-in U²-NetP binary.
- U²-NetP Ruby/Vips preprocessing parity: compact reference samples derived
  from the pinned upstream preprocessing path and immutable float32 NCHW
  tensors.
- An internal U²-NetP CPU inference/mask boundary: verified local artifact and
  ONNX port loading, a process-local `predict` limiter defaulting to one,
  finite `d0` normalization, and a one-band float Vips foreground mask at the
  source dimensions. It exposes no API endpoint or background composition.
- Observed Docker Vips CPU/8 GiB benchmark evidence at
  `docs/benchmarks/vips-cpu-8gb.md`.
