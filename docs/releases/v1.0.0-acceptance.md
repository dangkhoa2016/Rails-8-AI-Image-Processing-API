# v1.0.0 Final Acceptance Record

This document is the public acceptance record for the first stable source
release of Rails 8 AI Image Processing API.

`v1.0.0` is the project's first public community source release. Its final
accepted scope includes deterministic image processing, BiRefNet background
removal, and MobileSAM prompt segmentation.

## Release identity

- Version: `v1.0.0`
- Channel: stable
- Public prerelease: none
- First-publication corrective closeout date: 2026-09-23
- Tag form: annotated
- Authoritative source: the peeled target of `v1.0.0`
- Publication rule: the tag target equals the exact `main` SHA that completes
  all mandatory public-main CI gates successfully immediately before final
  corrective publication.
- Publication artifacts: the annotated tag, GitHub Release notes, and public
  evidence assets must describe that same final source and qualification state.

The first-publication version is intentionally not bumped. MobileSAM was
completed before the intended final publication boundary, so it is part of the
same `v1.0.0` release.

## Stable release scope

### Image processing

The authenticated Rails 8 multipart image-processing contract includes:

- `GET /images/capabilities`
- `POST /images/process` — deterministic Vips pipeline (JPEG, PNG, WebP)
- `POST /images/remove-background` — AI background removal using BiRefNet
- `POST /images/segment` — MobileSAM point/box prompt segmentation

The service applies explicit input/output/resource limits, strict validation,
metadata stripping, stateless tempfile cleanup, image-specific rate limiting,
and fail-closed AI behavior unless `IMAGE_AI_ENABLED=true`.

### BiRefNet boundary

- ONNX Runtime CPU inside Ruby
- optional deterministic solid-background composition via libvips
- model weights are not stored in Git
- exact filename, byte size, SHA-256, and runtime contract are pinned and
  verified before loading

### MobileSAM boundary

`POST /images/segment` accepts exactly one JSON prompt per request:

```json
{"type":"point","x":384,"y":385,"label":1}
```

or:

```json
{"type":"box","x0":192,"y0":192,"x1":577,"y1":578}
```

The response is a source-sized single-band binary PNG mask. The first public
contract intentionally excludes overlays, extraction, alpha-composited output,
base64 output, multiple prompts per request, and cross-request embedding cache.

MobileSAM runtime characteristics:

- ONNX Runtime CPU backend
- encoder and prompt-mask decoder sessions cached once per process
- one encoder inference plus one decoder inference per request
- shared single-flight AI limiter for the qualified workload
- no Python production inference service
- no GPU qualification

## Public CI and Docker release gates

The final `v1.0.0` corrective publication requires exact-main success for:

```text
full Rails tests                PASS

Ruby 3.2 compatibility          PASS
Ruby 4.0 compatibility          PASS
schema load                     PASS
RuboCop / repository policy     PASS
Brakeman                        PASS
bundler audit                   PASS
release contract                PASS
production Docker cold-build    PASS
```

The Docker cold-build gate performs a non-publishing `docker build --pull
--no-cache` on a GitHub-hosted runner. It does not publish GHCR images.

## Excluded scope

The `v1.0.0` source release does not claim:

- a hosted production deployment or live public endpoint;
- GHCR image publication;
- production-traffic or SLA qualification;
- GPU acceleration qualification;
- a Python production inference service;
- concurrency qualification beyond the documented single-flight workload;
- a theoretical minimum memory requirement.

## Corrective publication boundary

The pre-corrective `v1.0.0` tag and GitHub Release represented an earlier
snapshot of the same first-publication effort. The final corrective publication
must retarget `v1.0.0` to the exact reviewed `main` commit after all final CI
gates pass, and the existing GitHub Release must be updated to describe the
complete first-release scope above.

No later-version tag or GitHub Release is part of this project state.
