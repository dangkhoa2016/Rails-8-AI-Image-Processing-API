## Scope

`v1.1.0` adds MobileSAM prompt segmentation to the Rails 8 AI Image
Processing API while preserving the existing deterministic image-processing
and BiRefNet background-removal contracts.

The new public endpoint is:

```text
POST /images/segment
```

It requires an authenticated active user and multipart image upload. The
request supplies exactly one JSON prompt:

```json
{"type":"point","x":384,"y":385,"label":1}
```

or:

```json
{"type":"box","x0":192,"y0":192,"x1":577,"y1":578}
```

The response is a source-sized single-band binary PNG mask. The first public
contract intentionally excludes overlays, extraction, alpha-composited output,
base64 output, multiple prompts per request, and cross-request embedding cache.

## Runtime architecture

- Ruby 3.3 / Rails 8
- ruby-vips/libvips for image decode, autorotation, preprocessing, and mask
  encoding
- ONNX Runtime CPU backend for MobileSAM inference
- one encoder inference and one decoder inference per request
- encoder and decoder sessions cached once per process
- shared single-flight AI limiter with `IMAGE_AI_MAX_CONCURRENCY=1` for the
  qualified workload
- no Python inference service
- no GPU qualification in this release
